# Contraejemplos

El caso Hodge incluye `HODGE-E4-FALSE`: la afirmación euclídea $*^2=-I$ es falsa
en la forma $e^1\wedge e^2$. `genius.benchmark.execute` con rol `counterexample`
guarda la entrada, ambas imágenes y la diferencia exacta. Las pruebas alteran
además artefactos para verificar el rechazo de signos, cuadrados y rangos falsos.
