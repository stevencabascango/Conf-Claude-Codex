# Espacios de colaboración

`claude/` y `codex/` describen las fases separadas; `peer_review/` describe el
intercambio posterior. Los datos reales de un ciclo se generan bajo el directorio
de salida elegido con `prepare-pair`, y los informes se sellan antes del intercambio.
No se incluyen informes de investigación inventados para rellenar estas carpetas.

Consulta `docs/claude_codex.md` y `python3 -m genius --help`.
